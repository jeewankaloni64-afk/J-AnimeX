# J-AnimeX 🎬

J-AnimeX is an anime entertainment platform for discovering anime,
exploring trending titles, reading reviews, creating AI-powered
original anime stories, and managing a personal watchlist.

## Features

- 🔎 Anime search
- 🔥 Trending anime
- 🎭 Anime categories
- ⭐ Ratings and reviews
- ❤️ Watchlist
- 🤖 AI-powered original anime stories
- 👤 User accounts
- 💎 Premium section
- 📱 Mobile-friendly design

## Content Policy

J-AnimeX is designed for original, licensed, or legally permitted
anime content. It does not provide unauthorized downloads or
copyright-protected content without permission.
